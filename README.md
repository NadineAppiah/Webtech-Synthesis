# My Web Technologies Journey

## About the Project
My Web Technologies Journey is a simple website created as part of my Web Technology synthesis project. It brings together the HTML, CSS, and JavaScript concepts I have learned throughout the lessons.

## Features
- **Home:** Introduces the website.
- **About:** Provides information about the project.
- **Lessons:** Presents learning topics in HTML, CSS, and JavaScript, with images.
- **Contact Form:** Allows users to enter their name, email address, and message.
- **Interactive Welcome Button:** Displays a welcome message when clicked.
- **Form Validation:** Checks that the required fields are completed and displays a confirmation message when the form is submitted.

## Technologies Used
- HTML5 — for the structure and content of the website.
- CSS3 — for styling, layout, and responsive design.
- JavaScript — for interactivity and form handling.
- Git and GitHub — for version control and project hosting.

2. Open the project folder.
